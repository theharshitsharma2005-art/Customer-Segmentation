# 🛍️ Customer Segmentation Using K-Means Clustering

## 📌 Project Overview

This project applies **K-Means Clustering**, an unsupervised machine learning algorithm, to segment customers based on their purchasing behavior using the Online Retail dataset. Customer segmentation helps businesses understand different customer groups and enables personalized marketing strategies.

---

# 🎯 Objectives

* Clean and preprocess retail transaction data.
* Perform Exploratory Data Analysis (EDA).
* Standardize customer features.
* Determine the optimal number of clusters using the Elbow Method.
* Build a K-Means clustering model.
* Evaluate clustering performance using the Silhouette Score.
* Analyze customer segments for business insights.

---

# 📂 Dataset

This project uses the **Online Retail Dataset** available on Kaggle.

Download the dataset from:
https://www.kaggle.com/datasets/vijayuv/onlineretail

> **Note:** The dataset is not included in this repository. Please download it from the Kaggle link above before running the notebook.

# ▶️ How to Run

1. Clone this repository.
2. Download the dataset from Kaggle.
3. Place the dataset in the project folder.
4. Install the required libraries:

```bash
pip install -r requirements.txt
```

5. Open `customer_segmentation.ipynb`.
6. Run all cells.
